# Revisión entrega Proyecto 2

## Requisitos del proyecto

1. Escribir una clase para una perilla o un botón, que otro grupo deberá utilizar.
2. Incorporar 2 perillas.
3. Incorporar 2 botones pulsadores. Se pueden agregar más controles, pero que no sean pulsadores.
4. Se puede utilizar la misma pantalla del Proyecto 01.
5. Construir una carcasa de cartón o mediante impresión 3D.
6. Controlar la luz, el sonido y la pantalla.
7. Utilizar como referencia algún PC anterior al año 2010.
8. Tener en cuenta el lenguaje, los materiales y los colores.
9. Considerar el lenguaje interfásico (Mónica Jacobo y Gui Bonsiepe).
10. Crear un diagrama de usuario que muestre solo lo que visualiza el usuario.
11. Crear un diagrama de software.
12. Crear un diagrama de hardware.
13. Realizar el prototipo en Wokwi.
14. Crear una máquina que rinda tributo a un computador antiguo específico.

### KiCad

- Se trabajó con mayor profundidad en KiCad.
- `.sch`
  + Indica dónde están las conexiones y sus valores.
  + No importa el diseño ni la visualidad.
- `.pcb`
  + En este archivo sí importa el diseño del esquema.
- No olvidar guardar los avances.
- Agregar precios y URL en las propiedades de los componentes.

### Conceptos y componentes

- **CAD:** diseño asistido por computadora.
- `Module:RaspberryPi_Pico_Common_Unspecified`
  + Raspberry Pi Pico, corresponde al módulo completo y no solo al chip.
- `SW_Push`: botón pulsador.
- `D_LED`: diodo LED.

### Atajos de KiCad

- `A`: agregar símbolos, escribir y buscar componentes.
- `M`: mover.
- `T`: insertar texto para incluir documentación.
- `V`: valor.
- `G`: tomar y mover.
- `E`: propiedades.
- `L`: etiquetas de red.
- `R`: resistencia.

### Componentes electrónicos

1. Resistores: resistencia.
2. Capacitores: capacitancia.
