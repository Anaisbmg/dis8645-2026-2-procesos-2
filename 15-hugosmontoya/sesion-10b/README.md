# sesion-10b

## apuntes sesión
Hemos decidido que a partir del Apple Macintosh, que revolucionó la informática personal al popularizar para el público general con un precio "accesible" la interfaz gráfica de usuario (GUI),
en lugar de texto, en la pantalla aparecían iconos, donde organizar la información se convirtió en algo más visual. Nosotros tenemos pensado hacer una máquina computacional, a partir del Apple Macintosh que tenga diferentes íconos de carpetas en una interfaz gráfica de usuario como un escritorio donde con dos perillas controlas el cursor, con una perilla controlas el movimiento del eje x y en el otro el movimiento del eje y, con un botón tu puedes activar que se abra la carpeta donde tienes el cursor encima y con el otro botón le das play al video.

Es importante también destacar que el Apple Macintosh fue el ordenador que expandió de forma masiva el uso del ratón, un accesorio que para la época fue tan nuevo y tan pionero que habían revistas de época que 
debían explicar como funcionaba el ratón.

Es importante tener en cuenta que las clases son para crearlas una vez y usarlas varias veces, es decir que tenemos que hacer una clase por perillas y por botón.
Las clases se deben utilizar para subir todo lo que puede hacer esa clase. Por ejemplo creamos la clase de boton, con todas las funciones que puede hacer un botón y luego en cada botón uno y botón dos quitar aquellas funciones que no necesite cada uno.
