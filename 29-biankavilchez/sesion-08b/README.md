### Push button (pulsador)

Es un botón que permite ingresar una acción al sistema mediante una pulsación. Su funcionamiento depende del tipo de botón y de cómo esté conectado.

### Latch

Es un botón o mecanismo de control que conserva un estado después de presionarlo. Por ejemplo, una pulsación puede encender una luz y una segunda pulsación puede apagarla.

**Concepto clave:** permite alternar entre estados, como encendido y apagado.

### DIP switch

Es una pequeña caja que contiene varios interruptores. Cada interruptor permite seleccionar una posición para configurar opciones de un circuito o dispositivo.

### Potenciómetro lineal

Es un componente que permite modificar una resistencia mediante un control deslizante. Al conectarlo a un microcontrolador, puede utilizarse como entrada analógica para leer una posición o un valor.


### Encoder infinito

Es un control giratorio que detecta los pasos y el sentido de giro. Puede girar continuamente, sin tener un inicio o final fijo de recorrido.


### Botón con iluminación integrada

Es un botón que incorpora una fuente de luz, como un LED. Puede utilizarse para indicar que una función está activa o que el dispositivo está encendido.


### Perilla de selección

Es un mando giratorio que permite seleccionar opciones o modificar parámetros. Puede funcionar mediante un potenciómetro o un encoder, dependiendo del tipo de control utilizado.

### MIDI y controladores

MIDI (*Musical Instrument Digital Interface*) es un protocolo de comunicación utilizado para transmitir mensajes musicales y de control entre instrumentos, computadores y otros dispositivos.


###Ejercicio de clase:

Durante la clase se trabajó en cómo agregar un potenciómetro y un botón al sistema de una lucecita.

El ejercicio permite comprender la relación entre las entradas físicas, el código y la respuesta de una salida.

### Elementos del ejercicio

- **Botón:** permite activar una acción mediante una pulsación.
- **Potenciómetro:** permite modificar un valor mediante su posición.
- **Luz:** funciona como salida y responde a las instrucciones del programa.


### Organización del código en C++

En el ejemplo de clase, el programa se organiza en tres archivos con responsabilidades diferentes.

### `Lucecita.h` — Declaración de la clase

Declara la clase `Lucecita`, sus atributos y sus métodos. Define qué información contiene el objeto y qué acciones puede realizar.

Se puede entender como el archivo que describe qué ofrece la clase.

### `Lucecita.cpp` — Implementación de los métodos

Contiene el desarrollo de los métodos declarados en `Lucecita.h`. Aquí se define cómo se ejecutan las acciones de la clase.

### `main.cpp` — Uso de la clase

Es el archivo principal del programa. Crea una instancia u objeto de la clase `Lucecita` y le indica qué acciones realizar.
