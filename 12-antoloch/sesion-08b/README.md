## 3. Latch

- Es un interruptor que mantiene su estado hasta recibir una nueva activación.
- Permite alternar entre encendido y apagado con cada pulsación.
- A diferencia de un `pushbutton`, no requiere mantenerse presionado para conservar su condición.
- También puede implementarse mediante software, almacenando el estado en el microcontrolador.

## 4. DIP Switch

- Es un conjunto de pequeños interruptores integrados en un mismo encapsulado.
- Posee un tamaño similar al de un circuito integrado.
- Cada interruptor puede configurarse de manera independiente.
- Se utiliza para seleccionar configuraciones o parámetros de hardware.

## 5. Smalltalk

- Es un lenguaje de programación completamente orientado a objetos.
- Todos los elementos que participan en la ejecución son objetos.
- Las clases actúan como modelos para la creación de objetos.
- La comunicación entre objetos se realiza mediante el envío de mensajes.
- Funciona sobre una máquina virtual.
- Incluye un entorno de desarrollo integrado (IDE) que favorece la programación interactiva.
