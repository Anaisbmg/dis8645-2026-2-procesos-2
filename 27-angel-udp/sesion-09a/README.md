## apuntes sesión

Descargamos KiCad y vemos cómo utilizarlo en clase.

REPO es una supercarpeta con historial.

Vamos a trabajar con el módulo de Raspberry (la placa que hemos visto antes y con la que hemos trabajado).

En la entrega, hay que ponerles textos a las cosas o componentes en «Propiedades de texto».

Se pueden duplicar textos o elementos para copiar los atributos con Ctrl + D.

Hay un botón arriba que automatiza la aparición de números al duplicar o pegar elementos del mismo tipo. Por ejemplo: resistencia 1, resistencia 2 y, al final, resistencia 3.

Enseña a cerrar conexiones: se hace clic desde la salida del chip, luego otro clic para cambiar la dirección de la conexión y, finalmente, se conecta.

Existe la posibilidad de mover solo el objeto con la tecla M, lo que permite moverlo desconectando todo lo anterior. En cambio, con la tecla G, se mueve el objeto manteniendo las conexiones, como haciendo alusión a que M significa «mover» y G, «grupo».

Si hay un cuadrado verde en KiCad, significa que el componente no está conectado.

Con la tecla V se realizan cambios de nombre a los componentes.

Se agregan etiquetas para mantener el orden.

Se les pueden conectar X para las conexiones que no van.
