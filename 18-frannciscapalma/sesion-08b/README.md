El PWM (Pulse Width Modulation o Modulación por Ancho de Pulso) sirve para controlar la cantidad de energía o voltaje promedio que se envía a un dispositivo, utilizando señales digitales que solo alternan entre encendido (1) y apagado (0). [1, 2, 3]

Al variar rápidamente el tiempo que la señal pasa en estado "encendido" frente al estado "apagado" (lo que se conoce como ciclo de trabajo o duty cycle), se simula un nivel de voltaje intermedio sin desperdiciar energía en forma de calor. [1, 2, 3, 4]
