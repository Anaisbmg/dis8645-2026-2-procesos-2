### sistemas de partículas
**la naturaleza del código**
- técnica útil en gráficos por computadora
- muchas partículas representando en conjunto un objeto difuso, generando luego un sistema en donde se mueve, cambian y finalmente desaparece
- modelar diversos tipos de fenómenos naturales irregulares
- no limitar imaginación
- objetos independientes, puntos o formas simples
- clases que almacenan listas de instancias de otras clases
- herencia y polimorfismo -- utilizar solo una lista para almacenar objetos de diferentes tipos, así el sistema no es un sistema de un solo tipo de partículas
- emisor -- fuente de partículas, controla configuración inicial de partículas (posición, velocidad), flujo continuo o variación, estas partículas no existen indefinidamente
