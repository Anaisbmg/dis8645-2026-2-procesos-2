## Explicación proyecto-02

Grupos de 4, uno de 3.

 - Cada grupo escribe 1 clase (perilla o botón) y la comparte con otro grupo.

Debe contar con:

 - 2 perillas.
 - 2 botones.

La carcasa debe ser de cartón o impresión 3D.

 - **Importante:** Contemplar luz, LED, pantalla.

Rúbrica:

3 puntos grupales:

 - 1 = **Docs**
   - README
   - Diagramas de flujo
   - Bibliografía
   - Prompts
    
 - 1 = **Código**
   - Clases
   - Comentarios
   - Uso orden
    
 - 1 = **Interfaz**
   - Relato
   - Material
   - Usabilidad
   - Factura 

3 puntos individuales:

 - 1 = **Presentación oral**

## KiCAD

Spoiler: lo tengo desde el primer semestre del año pasado.

Igual lo actualicé porque tenía la versión 9.0.

Default - miSegundoEsquematico

Chip R2040 - chip de la raspi

Todo los componentes tienen:

 - Cuerpo (icono)
 - Referencia (R1, R2, R3...)
 - Valor (1k, 10k, 33k...)

**Comandos:**

 - M = mover
 - V = Valor
 - E = propiedades
 - T = texto
 - G = tomar y mover
 - L = etiquetas de red
